Privacy policy — Shorts Uploader

Last updated: November 18, 2026.

Shorts Uploader is a private tool used only by the owner of the doodlewhy YouTube channel.

What data it uses

With the owner's permission (Google OAuth), it uses the YouTube Data API to upload videos, set thumbnails, schedule publication and read view counts for the owner's own channel. It does not access any other account.

Where data is kept

The access token and video statistics are stored only on the owner's own computer. Nothing is sold, shared with third parties or used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
